Frontend para una app para la gestión de un gimnasio:
* Pantalla de login con 2 perfiles de ususario 


Usuario normal:
Puede definir sus datos personales y elegir un horario, también puede hacer logout 


Usuario administrador (monitor)
Puede Crear rutinas de ejercicios
Puede crear horarios para los distintos días de la semana
Puede definir sus propios datos personales 

Puede cambiar los datos personales de los ususarios normales 
Puede asignar usuarios a rutinas y a horarios del gimnasio 
Puede hacer logout
